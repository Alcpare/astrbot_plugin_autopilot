# 领航 (astrbot_plugin_autopilot)

AI 主动值守插件 v1.3.3 — 让 AI 主动发言、监听召唤、追踪好感度、控制发言频率、过滤用户发言、防护提示词注入。

## 安装

1. 将本插件目录放入 AstrBot 的 `data/plugins/astrbot_plugin_autopilot`。
2. 重启 AstrBot，插件自动出现在插件管理面板。
3. 在面板配置模型、机器人名字、目标会话等选项。
4. 内置指令：`/好感`、`/好感榜`、`/领航`、`/领航 状态`。

## 功能总览

| 功能 | 说明 |
|------|------|
| 定时发言 | 按固定间隔检查，让 AI 判断是否主动发言 |
| 消息监听 | 被 @ 或喊名字时自动触发 AI 发言 |
| 好感度追踪 | AI 根据对话语气自动评估对每个用户的好感 |
| 好感榜 | 每 3 分钟在控制台更新总览，支持 `/好感榜` 查询 |
| 频率控制 | 档位制控制 AI 发言频率和字数 |
| 人格注入 | 所有发言路径均可注入 LLM 人格 |
| 记忆回溯兼容 | 发言前自动读取记忆回溯插件的历史记忆 |
| 发言过滤 | 关键词/字数/行为准则/情感策略，拦截后不回复 |
| 注入防护 | 拦截规范书/符号语言/系统指令等试图改写机器人的消息 |

### 消息处理顺序

```
收到消息
   │
   ▼
① 运行开关检查 (running_enabled)
   │
   ▼
② 好感榜清除按钮检测
   │
   ▼
③ 上下文记录 (enable_context)
   │
   ▼
④ 消息监听检测 (被@/喊名字?)
   │
   ├──是──→ 读取监听上下文 ──→ 调用发言管道 ──→ 发送
   │
   └──否──→ 继续
   │
   ▼
⑤ 好感度评估 (affinity_enabled)
   │
   ├──冷却通过──→ LLM评估语气 ──→ 更新分数 ──→ 检测升级事件
   │
   └──冷却中──→ 跳过
```

```
定时发言 / 消息监听 / 手动发言
   │

   │
   ▼
② 注入人格 ──→ (persona_inject)
   │
   ▼
③ 注入历史记忆 ──→ (rememory_compat)
   │
   ▼
④ 注入好感度变化 ──→ (affinity_integration)
   │
   ▼
⑤ 注入频率档位限制 ──→ (speak_frequency)
   │
   ▼

   │
   ▼

   │
   ├──超过上限──→ 按句尾截断
   │
   ├──低于最短──→ 不发送 (纯标点除外)
   │
   └──正常──→ 发送
```

## 指令

| 指令 | 功能 |
|------|------|
| `/领航` 或 `/领航 状态` | 查看插件运行状态（受 `enable_status` 开关控制） |
| `/好感` | 查看 LLM 对你的好感度（分数、等级、进度条） |
| `/好感榜` | 查看好感度排行榜（仅显示与 LLM 对话过的用户） |

## 配置说明

所有配置在 AstrBot 面板 → 插件管理 → 领航 中调整。

### 运行控制

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `running_enabled` | 开 | 总运行开关，关闭后暂停所有主动功能 |
| `enable_proactive` | 开 | 定时发言开关 |
| `enable_commands` | 开 | 手动指令开关（`/好感` `/好感榜`） |
| `enable_status` | 开 | `/领航` 和 `/领航 状态` 开关 |
| `enable_context` | 开 | 聊天上下文记录开关 |

### 定时发言

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `check_interval` | 1800 秒 | 每隔多少秒检查一次是否主动发言 |
| `proactive_require_new_messages` | 开 | 仅当会话出现新消息时才进行主动发言判断 |
| `ai_judge_enabled` | 开 | 开启=先让 AI 判断是否值得发言；关闭=直接生成发言 |
| `unified_judge_provider` | 空 | 统一判断模型；留空使用默认对话模型 |
| `judge_provider` | 空 | 定时发言判断专用模型；留空跟随统一判断模型 |
| `cooldown_seconds` | 600 秒 | 同一会话两次主动发言的最小间隔 |
| `max_context_messages` | 10 | 判断时读取的最近消息数 |
| `check_prompt` | 内置 | 主动检查提示词，回复"不发送"则沉默 |
| `target_sessions` | `[]` | 目标会话 ID 列表，留空自动跟踪活跃会话；格式 `platform:type:id` |

### 消息监听

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `listen_enabled` | 开 | 消息监听开关 |
| `listen_provider` | 空 | 监听判断 LLM 模型（可独立选择） |
| `listen_context_messages` | 20 | 被召唤时读取的上下文条数 |
| `listen_cooldown` | 30 秒 | 触发冷却（单位秒） |
| `listen_skip_at` | 开 | 被 @ 时交给主对话回复，避免双回复 |
| `bot_names` | `[]`（需自行配置） | 触发监听的名字列表，示例：["助手"] |

### 好感度

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `affinity_enabled` | 开 | 好感度追踪开关 |
| `affinity_provider` | 空 | 好感度判断 LLM 模型（建议用轻量模型） |
| `affinity_cooldown` | 5分钟 | 同一用户两次好感评估的最小间隔 |
| `affinity_integration` | 开 | 定时发言时注入好感度变化给 AI |
| `display_enabled` | 开 | 后台每 3 分钟打印好感度总览 |

#### 清除好感榜

| 配置项 | 说明 |
|--------|------|
| `clear_affinity_button` | 清除：仅保留 65 分及以上，其余重置为默认 30 分（默认关） |
| `clear_affinity_all_button` | 全部清空：删除所有记录从头开始（默认关） |

两个清除开关触发后自动复位为关，不会重复触发。

### 输出控制

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `persona_inject` | 开 | 全局注入 LLM 人格（定时/监听/手动发言均生效） |
| `rememory_compat` | 开 | 兼容记忆回溯插件，发言前注入历史记忆 |
| `speak_frequency` | 克制 | 发言频率档位 |

#### 频率档位

| 档位 | 频率要求 | 字数上限 | 最短字数 |
|------|---------|---------|---------|
| 极克制 | 绝不允许频繁发言，非说不可才开口 | 50字 | 7字 |
| 克制 | 必须克制，拿不准就沉默 | 57字 | 5字 |
| 正常 | 不连续插话，每句话要有价值 | 72字 | 3字 |
| 活跃 | 积极但有节制，不刷屏 | 87字 | 2字 |

每个档位同时约束：
- 频率：提示词告知 AI 发言克制程度
- 字数上限：超过则按句尾截断
- 最短字数：低于则视为废话不发送（纯标点无语消息如"……"除外）

> **网页搜索豁免**：网页搜索请求不参与以上频率控制。`apply_frequency_global` 会识别搜索关键词（搜索/搜一下/搜搜/帮我搜/帮我查/查一下/查查/百度/谷歌/google）或系统提示中的 `web_search`/`baidu_ai_search`/`搜索工具`，直接跳过频率/字数/换行/工具约束注入，避免搜索结果被压缩或拆分成多条消息。

## 好感度系统

- **方向**：LLM 对用户的好感（AI 视角评估用户语气）
- **初始值**：30 分（范围 0-100）
- **等级**：陌生人(0-20) → 初识(20-40) → 熟络(40-60) → 好朋友(60-80) → 知己(80-100)
- **评估冷却**：同一用户每 5 分钟评估一次，每次 ±10 分
- **上榜条件**：仅显示与 LLM 真正对话过的用户（`talked` 标记）
- **去重**：按 QQ 号合并，同一用户跨群多个昵称时显示最短的那个

### 好感等级图例

```
 0         20         40         60         80         100
 ├──────────┼──────────┼──────────┼──────────┼───────────┤
 陌生人  ──→  初识  ──→  熟络  ──→  好朋友  ──→  知己
 │          │          │          │          │
 无好感     一般认识    聊得来      亲密       挚友
```

### 清除规则

```
清除好感榜 (clear_affinity_button)
  │
  ├── 分数 ≥ 65 ──→ 保留（标记不变）
  │
  └── 分数 < 65 ──→ 重置为30分 ──→ 取消对话标记

全部清空 (clear_affinity_all_button)
  │
  └── 删除所有记录+事件 ──→ 标记全部消失
```

## 生态兼容

- **记忆回溯** (`astrbot_plugin_rememory`)：发言前读取该会话历史记忆注入给 AI
- **人格系统**：通过 `persona_inject` 注入会话人设

## 消息处理流程

```mermaid
flowchart TD
    A[QQ 消息] --> B{过滤模块<br/>优先级1000}
    B -->|关键词/字数/规则命中| X[stop_event 拦截<br/>不回复]
    B -->|放行| C[上下文记录]
    C --> D{监听判断<br/>@或喊名字?}
    D -->|是| E[领航发言管道]
    D -->|否| F[好感度评估<br/>LLM 判断 ±分]
    C --> F
    E --> G[发言频率/人格/记忆注入]
    F --> H[事件记录/等级变化]
    G --> I[发送前处理<br/>压平换行·去句号·截断]
    E --> I
    I --> J[QQ 回复]
```

- **v1.0.0**：初版，定时主动发言

## 数据存储

插件数据保存在插件目录 `data/` 下：
